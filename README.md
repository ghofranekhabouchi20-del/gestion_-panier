# Gestion de Panier

## Présentation du projet
Gestion de Panier est une application web qui permet
aux utilisateurs de consulter des produits et de gérer
leurs achats dans un panier.

## Objectifs
- Consulter les produits.
- Ajouter des produits au panier.
- Modifier les quantités.
- Supprimer des produits.
- Calculer le prix total.

## Technologies utilisées
- HTML
- CSS
- JavaScript
- Git et GitHub

## Auteur
Réalisé dans le cadre d'un projet informatique.
